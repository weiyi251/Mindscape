# 日期便签（官方示例外部插件）

一个「最小但真实可用」的外部插件：在画布空白处右键点「新建日期便签」，就在右键位置
创建一张便签，正文已经写好今天的日期与星期（如 `2026-09-20 周日`）。

它演示了外部插件的全部骨架：`manifest.json` 清单契约、ES module 入口、
`activate(api)` 注入式注册、画布菜单扩展点与 `api.board.createCard` 无文件建卡。
想写自己的插件，从这个文件夹改起即可。

## 安装

1. 把整个 `example.dated-note` 文件夹复制到 `%APPDATA%\Mindscape\plugins\`
   （资源管理器地址栏直接粘贴 `%APPDATA%\Mindscape\plugins` 回车）；
2. 打开 Mindscape → 设置面板 → **插件** → 点 **刷新**；
3. 列表出现「日期便签」（外部插件默认只登记不启用）→ 点 **启用**。

## 真机验证清单

- [ ] 插件页「刷新」后列表出现「日期便签」，来源显示「外部」，状态为未启用
- [ ] 点「启用」后无报错，「详情」里已注册内容显示「画布菜单项 1」
- [ ] 进入任意空间，画布空白处右键出现「新建日期便签」（在「新建便签 / 粘贴」与「撤销 / 重做」之间）
- [ ] 点击后右键位置建出便签，正文为今天的日期与星期
- [ ] `Ctrl+Z` 可撤销（便签卡无文件，撤销只删卡）
- [ ] 停用插件后右键菜单该项立即消失；已有便签不受影响
- [ ] 「卸载」删除安装目录（插件从列表消失）；重新复制文件夹可再次安装
